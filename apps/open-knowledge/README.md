# Open Knowledge Desktop

Electron and Svelte desktop editor for local Markdown workspaces. Markdown files remain the source of truth, with additional features enabled for explicitly detected [Open Knowledge Format](docs/open-knowledge-format.md) workspaces.

```bash
bun install
bun run dev
```
