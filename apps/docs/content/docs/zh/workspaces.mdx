description: 基于文件夹的工作区、文件浏览、预览、标签页和窗口。

工作区由一个文件夹构成。打开过程不执行导入或复制。文件保留在原位置。

## 侧边栏

侧边栏显示工作区及其子文件夹中的文件。文件夹排列在文件之前。

文件列表筛选范围为文件和文件夹名称。文档正文不在筛选范围内。

## 文件访问状态

每个文件具有以下访问状态之一：

| 状态 | 本地文件 | 行为 |
| --- | --- | --- |
| 可编辑 | Markdown 文件 | 可在富文本或 Markdown 源代码视图中打开并保存。 |
| 只读 | 支持的 PDF、文档、演示文稿、电子表格、RTF、EPUB 和 CSV 文件 | 以生成的 Markdown 预览打开。原文件不会被修改。 |
| 无法预览 | 其他文件类型 | 打开说明该文件类型无法显示或编辑的页面。文件仍显示在侧边栏中。 |

只读文件在侧边栏和标题栏中显示锁定图标。无法预览的文件显示带问号的文件图标。只读预览是临时内容，不会写回源文件。

部分具有受支持扩展名的文件仍可能无法预览，例如加密文件或结构无效的文档。

远程工作区使用远程知识包为每个文件报告的访问状态。工作区为只读时，标记为可编辑的文件也按只读方式打开。对于未报告文件状态的旧版远程知识包，Markdown 文件遵循工作区权限，其他文件类型显示无法预览页面。

## 创建与整理

新文档的创建位置包括工作区根目录、所选文件夹和当前文档所在目录。缺少 `.md` 扩展名时，由应用自动补充。

文件和文件夹支持重命名与删除。`index.md` 和 `log.md` 的重命名与删除被禁用。删除操作仅适用于空文件夹。跨文件夹移动当前未提供。文档重命名不触发链接更新。

## 标签页与窗口

文档在标签页中打开。支持的标签页操作包括重新排列、批量关闭和在独立文档窗口中打开。显示同一工作区的窗口之间支持标签页转移。

标签页状态仅在当前应用会话中保留。应用关闭后不恢复。

## 外部工具

工作区保持普通文件夹结构。同一内容由 Git 客户端、同步服务、备份工具和其他 Markdown 编辑器处理。

<Callout title="外部文件修改">
  其他应用产生的修改显示在 Open Knowledge 中。未包含本地修改的已打开文档自动刷新。存在本地修改时，自动替换被禁用。
</Callout>
