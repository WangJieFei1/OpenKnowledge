---
title: 设置
description: 全局默认设置、项目覆盖、编辑器选项和格式规则。
---

全局设置为所有工作区提供默认值。项目设置会覆盖当前工作区的全局默认值，并应用于该工作区的工作区窗口和文档窗口。共享项目覆盖保存在 `.open-knowledge/settings.json` 中，可在设置窗口中重置。系统路径的启用状态改为保存在仅所有者可访问的应用数据中，因此项目内容无法自行启用。

## 外观

| 设置     | 选项                                                                               | 含义                                     |
| -------- | ---------------------------------------------------------------------------------- | ---------------------------------------- |
| 颜色模式 | 系统、浅色、深色                                                                   | 与操作系统主题同步，或固定为浅色或深色。 |
| 颜色主题 | Indigo、Blue、Cyan、Teal、Green、Grass、Orange、Red、Crimson、Pink、Purple、Violet | 控件强调色。                             |
| 语言     | English、简体中文                                                                  | 菜单、标签和消息使用的语言。             |

## 编辑器

| 设置                 | 选项                               | 含义                                 |
| -------------------- | ---------------------------------- | ------------------------------------ |
| 书写控件             | 工具栏、斜杠命令、两者             | 富文本格式操作的提供方式。           |
| 标题栏中的编辑器模式 | 显示、隐藏                         | “富文本”和“Markdown”按钮的显示状态。 |
| 文档字体             | 书籍衬线体、系统无衬线体、等宽字体 | 富文本文档使用的字体。               |
| 字号                 | 13-24 px                           | 富文本文档的文字大小。               |

## 侧边栏

侧边栏显示状态由设置、标题栏和 Ctrl+B（macOS 上为 Command+B）控制。宽度通过拖动分隔线调整。布局设置自动保存。

## 项目格式

项目设置中提供**严格 Open Knowledge Format**选项。启用后，应用会检查每个非保留概念 Markdown 文件是否包含 YAML frontmatter 和非空字符串 `type`。缺少这些元数据时，编辑器会显示非阻塞错误和 frontmatter 修复操作；文档仍可打开和保存。

严格模式还会为新建概念文档提供 Open Knowledge 模板。未启用严格模式时，只有位于带版本声明的 `index.md` 所在文件夹及其后代文件夹中的新文档会使用该模板。保留文件 `index.md` 和 `log.md` 不需要概念元数据，并且只在这些范围内获得 Markdown 标题。

## 链接路径

项目设置中的**从项目根目录解析绝对路径**默认启用。因此，`/guides/start.md` 等 Markdown 链接会解析为当前项目内的 `guides/start.md`。相对链接从当前文档所在文件夹解析，并且不能越过项目根目录。

禁用此设置后，绝对链接会改为打开对应的操作系统路径。系统路径访问需要为每个项目明确启用，并由桌面主进程再次检查。

如果已知项目路径上的文件夹被替换，Open Knowledge 会要求重新选择该文件夹。重新选择会清除系统路径启用状态，并撤销之前的 MCP 授权。
