---
title: 文档编辑
description: 编辑视图、文字格式与保存方式。
---

可编辑的 Markdown 文档提供富文本和 Markdown 源代码两种编辑视图。编辑器模式控件默认显示于标题栏，其显示状态由设置控制。只读预览不提供编辑控件。

| 编辑方式 | 显示内容 | 使用范围 |
| --- | --- | --- |
| 富文本 | 文档正文，YAML 字段显示在属性面板中 | 常规文档编辑与排版 |
| Markdown 源代码 | 完整的 `.md` 文件 | Markdown 或 YAML 源代码编辑 |

文件顶部的 YAML 属性解析失败时，源代码视图自动启用，原始内容保留。

## 文字格式

富文本支持标题、列表、链接、URL 图片、引用、代码、分隔线、表格、删除线和硬换行。

原始 HTML、任务列表、脚注、数学公式和 MDX 等特殊语法由源代码视图处理。使用富文本编辑文档时，不受支持的语法可能被更改或移除。

## 书写控件

书写控件包含工具栏、`/` 命令和两者并用三种模式。文本选择区域和上下文菜单提供常用格式操作。

`@` 用于打开其他 Markdown 文档列表。选中的文档以普通 Markdown 链接形式插入。

## 保存

修改自动保存。Ctrl+S 或 Command+S 触发立即保存。文件被其他应用修改且当前文档不包含待保存内容时，新版本自动载入。

<Callout type="warn" title="同一文件在两处发生修改">
  同一文件在多个位置发生修改时，系统显示磁盘冲突。自动替换被禁用。从磁盘重新加载后，磁盘版本将替换本地草稿。
</Callout>
