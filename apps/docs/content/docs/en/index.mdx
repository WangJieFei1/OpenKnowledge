---
title: Open Knowledge Guide
description: Open a Markdown folder, edit notes, and choose what a connected agent can read.
---

Click **Open folder** and choose a directory that contains Markdown files. Open a note to edit it in rich text or switch to Markdown source. Both views save to the same file, so you can check the changes in Git or open it in another editor.

A workspace is just that folder. You don't need to add YAML properties or convert your notes. If the folder already uses the [Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md), the editor also recognizes its standard properties and supporting documents.

## Share a folder with an agent

Opening a folder doesn't share it. In **MCP Settings**, set the workspace to **Read** if you want a connected agent to look things up. Leave other projects **Off**. The [connection guide](/docs/mcp) explains how to connect a client and revoke access.
