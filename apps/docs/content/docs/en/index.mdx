Open Knowledge is a desktop editor for Markdown knowledge bases. A folder of `.md` files can be opened directly. Its documents can be edited in rich text or source view, while the same files remain available to other Markdown tools.

## Markdown first

Files stay in the selected folder as plain Markdown. YAML properties at the top of a file, often called frontmatter, are optional. Git, sync services, and other editors can continue to work with the same files.

## Open Knowledge Format compatibility

The [Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) is supported, but it is not required. Existing bundles open without conversion. Common properties and supporting documents receive additional editor support.

Regular Markdown folders remain supported when they use custom metadata or no frontmatter at all.
